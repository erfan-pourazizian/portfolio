# Erfan Pourazizian — Portfolio

Static HTML/CSS portfolio based on the provided CV.

## Files

- `index.html` — portfolio page
- `style.css` — all styles
- `images/` — put project screenshots here
- `Erfan-Pourazizian-CV.pdf` — optional CV file

## Adding screenshots

The project cards currently use visual placeholders. Replace each `.image-placeholder` block with an `<img>`.

Example:

```html
<div class="project-image">
  <img src="images/food-reservation.jpg" alt="Food Reservation System screenshot">
  <span class="project-number">01</span>
</div>
```

Recommended screenshot names:

- `food-reservation.jpg`
- `marketplace.jpg`
- `sso.jpg`
- `learning.jpg`
- `documents.jpg`
- `ai-chatbot.jpg`

The design is intentionally image-focused: once real screenshots are inserted, they become the main visual element of each project card.
